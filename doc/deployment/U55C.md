# Alveo U55C

[Deployment index](README.md)

| Field | Value |
|---|---|
| Part | `xcu55c-fsvh2892-2L-e` |
| Family | Virtex UltraScale+ HBM |
| BRAM tiles | 2016 |
| UltraRAM blocks | 1936 |
| HBM2 bandwidth | 460 GB/s aggregate |

## Reference configuration

```text
512 KiB
WAYS=8
LINES=1024
LINE_W=16
POLICY=GRASP
DB_LATENCY=2
DATABANK_SDP=1
INCLUDE_VICTIM=0
```

The canonical historical post-route record is in
[`syn/vivado/sweep_results.md`](../../syn/vivado/sweep_results.md). Its small
margin requires a current rerun with the intended floorplan and surrounding
logic.

## Capacity example

| Aggregate configuration | UltraRAM | BRAM |
|---|---:|---:|
| 16 × 512 KiB | 256 | 80 |
| 32 × 512 KiB | 512 | 160 |
| 16 × 1 MiB | 544 | 32 |
| 32 × 1 MiB | 1088 | 64 |

U55C provides more UltraRAM headroom than U250 and includes HBM2. The cache
master must still be integrated through the platform interconnect and HBM IP.

## Reproduce

```bash
cd syn/vivado
SIZE=512K PERIOD_NS=4.0 DB_LATENCY=2 \
DATABANK_SDP=1 INCLUDE_VICTIM=0 PNR=1 \
./u55c_synth.sh
```

Sweep `CASCADE_DEPTH` for 1 MiB and larger arrays.
