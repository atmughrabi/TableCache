## Recommended configuration for graph-accelerator deployments

```sv
l2_cache #(
    .POLICY              (GRASP),
    .LINES               (1024),     // 512 KB at LINE_W=16
    .LINE_W              (16),
    .WAYS                (8),
    .BLOCK_W             (32),
    .DB_LATENCY          (3),        // tuned for 300 MHz
    .INCLUDE_VICTIM      (0),
    .DATABANK_SDP        (1),
    .SDP_WRITE_INPUT_REG (1)         // tuned for 300 MHz
    // ADDR_RANGE_L / ADDR_RANGE_H per system map
) u_cache ( /* AXI */ );
```

Vivado synth/PnR knobs:
```bash
PERIOD_NS=3.333 DB_LATENCY=3 SDP_WRITE_INPUT_REG=1 \
  PLACE_DIRECTIVE=ExtraNetDelay_high \
  PHYS_DIRECTIVE=AggressiveExplore \
  ROUTE_DIRECTIVE=AggressiveExplore \
  PART=xcu250-figd2104-2L-e PNR=1 \
  ./syn/vivado/u55c_synth.sh
# (u55c_synth.sh accepts PART override; sets the U250 part correctly)
```

## Caveats

- The 1 MB / 8w configuration at 250 MHz baseline is -0.122 ns
  post-route (~243 MHz). For deployments locked to 250 MHz baseline,
  use the tuned knobs (they close at 302 MHz, comfortably above 250).
- Multi-CU bring-up should confirm device-wide timing with the
  surrounding shell context — OOC numbers don't model NoC/IO latency.

## `CASCADE_DEPTH` knob (URAM cascade length)

UltraScale+ HBM uses the `URAM288` primitive (vs Versal's `URAM288E5`
on V80). On UltraScale+ the URAM cascade is fast enough that small
arrays (512 KB) prefer the Vivado-default `CASCADE_DEPTH=8`, while
larger arrays (1 MB+) benefit from `CASCADE_DEPTH=1` (no cascading,
replace with parallel LUT mux). Default stays at 8; override per build.

| Cache | `CASCADE_DEPTH=8` (default) | `CASCADE_DEPTH=1` |
|---|---|---|
| 512 KB | recommended (cascade is short, fast) | regresses (mux fanout dominates) |
| 1 MB   | acceptable | recommended (+~0.1 ns post-route WNS) |
| 2 MB   | not measured | likely recommended |

Override:

```bash
CASCADE_DEPTH=1 SIZE=1M PERIOD_NS=3.333 DB_LATENCY=3 \
  SDP_WRITE_INPUT_REG=1 PLACE_DIRECTIVE=ExtraNetDelay_high \
  PHYS_DIRECTIVE=AggressiveExplore ROUTE_DIRECTIVE=AggressiveExplore \
  PNR=1 ./u55c_synth.sh
```
