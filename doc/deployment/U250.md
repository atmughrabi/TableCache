## Reference configuration

```text
512 KiB
WAYS=8
LINES=1024
LINE_W=16
POLICY=GRASP
DB_LATENCY=2
DATABANK_SDP=1
INCLUDE_VICTIM=0
```

The recorded post-route result at 250 MHz is +0.088 ns WNS. A 1 MiB
configuration at the same baseline settings measured -0.122 ns WNS.

Device-level closure must include the surrounding interconnect and memory
system. Leave routing headroom for other UltraRAM users.

## Synthesis check

```bash
cd syn/vivado
PART=xcu250-figd2104-2L-e \
WAYS=8 LINES=1024 LINE_W=16 POLICY=5 \
DATABANK_SDP=1 DB_LATENCY=2 INCLUDE_VICTIM=0 \
./run_synth.sh
```

This command verifies OOC synthesis, resource inference, and post-synthesis
timing. The generic UltraScale+ place-and-route flow can target U250 with:

```bash
PART=xcu250-figd2104-2L-e SIZE=512K PNR=1 \
POLICY=5 DB_LATENCY=2 DATABANK_SDP=1 INCLUDE_VICTIM=0 \
./u55c_synth.sh
```

Final system timing must still be measured in the containing design. For
larger arrays, sweep `CASCADE_DEPTH={1,2,4,8}`.
