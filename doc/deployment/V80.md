# Alveo V80

[Deployment index](README.md)

| Field | Value |
|---|---|
| Part | `xcv80-lsva4737-2MHP-e-S` |
| Family | Versal Premium |
| Silicon model | engineering sample |
| BRAM tiles | 3741 |
| UltraRAM blocks | 1925 |

The engineering-sample timing model reports higher clock uncertainty than
production UltraScale+ parts. Treat OOC frequency comparisons across families
as indicative rather than directly equivalent.

## Reference configuration

```text
512 KiB
WAYS=8
LINES=1024
LINE_W=16
POLICY=GRASP
DB_LATENCY=2
DATABANK_SDP=1
INCLUDE_VICTIM=0
CASCADE_DEPTH=1
```

The recorded post-route result at 200 MHz is +0.062 ns WNS.

## Capacity example

| Aggregate configuration | UltraRAM | BRAM |
|---|---:|---:|
| 16 × 512 KiB | 256 | 80 |
| 32 × 512 KiB | 512 | 160 |
| 16 × 1 MiB | 544 | 32 |
| 16 × 2 MiB | 1056 | 32 |

Large arrays are typically limited by UltraRAM cascade and routing delay.
Banking and `CASCADE_DEPTH` can reduce per-bank depth, but must be evaluated
with post-route timing.

## Reproduce

```bash
cd syn/vivado
SIZE=512K PERIOD_NS=5.0 DB_LATENCY=2 \
DATABANK_SDP=1 INCLUDE_VICTIM=0 CASCADE_DEPTH=1 PNR=1 \
./v80_synth.sh
```

System-level Versal NoC timing is outside the OOC cache result.
